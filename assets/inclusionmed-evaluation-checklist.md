# InclusionMed evaluation record — working checklist

## Task & data
- Benchmark and task IDs, dataset version, included subsets, access conditions and licence.

## Model & setup
- Exact model version, prompts, tools, input format and any system instructions.

## Run conditions
- Sampling settings, output limits, repeats, retries, failures and deviations from the protocol.

## Scoring & review
- Metric and scale, reference sources, scoring rubric, critical errors and qualified reviewers.

## Results & uncertainty
- Task-level results, sample size, variation across runs where measured, and missing results.

## Reproduction & credit
- Code version, run instructions, reviewable outputs, source attribution and contributor roles.

Status: proposed reporting checklist, not a released evaluation protocol.
